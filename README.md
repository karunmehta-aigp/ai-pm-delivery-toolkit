## What's in this repository

This repository is organized into standalone projects, each focused on a different layer of running AI programs responsibly.

| Project | What it covers |
|---|---|
| [Project 1 — AI Program Delivery](./project-1-ai-delivery/) | The learning roadmap: AI literacy, program lifecycle, failure modes, judgment layer, change management, and how to build proof of experience |
| [Project 2 — AI PM Prompts](./project-2-ai-prompts/) | The prompt library: 30 governed, auditable prompts (PM-01 through AI-PM-05) covering intake through release, plus a day-to-day lifecycle prompt map |

---

## How to use this repository

- **New to AI program management?** Start with [Project 1](./project-1-ai-delivery/) — it builds the conceptual foundation before you touch the prompts.
- **Need a prompt for a specific task right now?** Go straight to [Project 2](./project-2-ai-prompts/) — every prompt includes a sample output so you know what to expect before running it.
- **Preparing for an AI PM interview or building portfolio proof?** Both projects are designed to be used together — the roadmap gives you the story, the prompts give you the artifacts.
